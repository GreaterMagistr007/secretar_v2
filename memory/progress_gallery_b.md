# Галерея макетов «Календарь» — блок B (v11–v20)

Агент: gallery-b. Каталог: public/gallery/. Файлы: v11.html … v20.html.
Правила: самостоятельные HTML, инлайновый CSS/JS, без внешних зависимостей.
Общее для всех: месяц/год из new Date(), модалка выбора месяца (сетка/список 12 месяцев,
стрелки года, закрытие по фону и Esc), неделя с понедельника, выделение сегодня,
демо-задачи вычисляются детерминированным хешем прямо в файле, интерфейс на русском.

## Ход работы
- v11 «11. Хвоя / список задач под календарём» — компактная тёмно-зелёная шапка (месяц-кнопка + «Сегодня»),
  сетка с точками задач, ниже карточка со списком задач ВЫБРАННОГО дня (клик по дню меняет список).
  Модалка — нижний шит с сеткой 3x4 сокращённых месяцев. Палитра: хвоя #14432c / #2f7d53, акцент терракота.
- v12 «12. Бирюза / колонка номеров недель» — слева тёмно-бирюзовая вертикальная полоса с ISO-номерами недель
  (текущая неделя подсвечена), справа сетка в рамке-карточке; метки задач — горизонтальные полоски.
  Модалка — центральный диалог со СПИСКОМ 12 месяцев и числом дней в каждом. Палитра: #0d8b86 / #075c59.
- v13 «13. Янтарь / кнопка добавления в углу» — шапка по центру (месяц над годом, подсказка), сетка-карточка,
  дни с задачами залиты янтарным, число задач подписано цифрой под датой, точка «всё выполнено».
  Внизу FAB «+» справа и полоска-итог по месяцу; клик по дню и по FAB даёт всплывающую подсказку.
  Модалка — центральный диалог 3x4 с круглыми стрелками года. Палитра: #e0930c / #a86505.
- v14 «14. Светлый графит / воздушная компактная сетка» — максимум воздуха: широкие поля 28px, крупные
  вертикальные интервалы, мелкие строчные дни недели с трекингом, дни — маленькие кружки 26px, метки — точки 3px.
  Под сеткой тонкая линейка и блок «сколько задач на выбранный день» + кнопка «Сегодня».
  Модалка — минималистичный диалог без заливок, месяцы строчными. Палитра: светло-серая #f7f7f8 / графит #2b2d31.
- v15 «15. Океан / квадраты-заливка по загруженности» — heatmap: ячейка-квадрат заливается одним из 6 оттенков
  по числу задач (выходные автоматически спокойнее), внизу шкала «тише → плотнее» и панель с уровнем дня.
  В модалке у каждого месяца полоска средней загруженности. Модалка — нижний шит, сетка 4x3. Палитра: океан #0f7a86 / #08505e.
- v16 «16. Сакура / «Сегодня» слева, месяц справа» — обратный порядок шапки: слева квадратная кнопка «Сегодня»
  с числом, справа выровненный по правому краю месяц и год; градиентная подложка шапки, ячейки-лепестки
  (скруглённые снизу), метки задач — ромбы-лепестки. Модалка — 2 колонки полных названий месяцев. Палитра: розовая #e2688f.
- v17 «17. Брутализм / чёрно-жёлтый моноширинный» — моноширинный шрифт, рамки 3–4px, жёсткие тени со смещением
  6px без размытия, дни двузначные (01, 02), число задач — чёрная плашка-бейдж, «горячие» дни красные.
  Панель-список задач под сеткой, кнопки-блоки. Модалка — коробка с чёрной шапкой и тенью жёлтым. Палитра: #0a0a0a / #ffe000 / акцент #e03c00.
- v18 «18. Стекло / размытая шапка на градиенте» — фиксированный сине-фиолетовый градиент с размытыми пятнами,
  sticky-шапка с backdrop-filter blur, карточка сетки и нижние блоки — полупрозрачное стекло с тонкой светлой обводкой.
  Метки — мятные и розовые точки. Модалка тоже стеклянная, с блюром фона. Палитра: #3b2a8c→#5b31a8, акценты #8ef0d8 / #ffb3e6.
- v19 «19. Терракота / недели-карточки» — вместо единой сетки список карточек-недель: у каждой заголовок
  (номер недели / «Текущая неделя», диапазон дат, сумма задач) и строка из 7 дней с подписью дня недели
  в каждой ячейке; метки — ромбики, домашние дела оливковые. Модалка — нижний шит. Палитра: терракота #c0562f / #8c3a1c.
- v20 «20. Неон / тёмная тема со свечением» — тёмный фон #0a0c14 с радиальными подсветками, заголовок месяца
  со свечением текста, ячейки-плитки, метки задач — светящиеся точки трёх цветов (работа/личное/срочное) с box-shadow,
  легенда категорий, «сегодня» обведён неоновой рамкой. Модалка тёмная со свечением. Палитра: #37f5c5 / #b46cff / #ff4f9a.
