Завершённая загрузка забывается: успешная с верным размером — только забыть (DownloadManager.remove удалил бы и готовый файл), ошибка или неверный размер — remove(id) вместе с файлом, ошибка отдаётся веб-части один раз. Запись пропала (отменили в «Загрузках») — забыть, дальше по файлу. Файл не той длины без загрузки — удаляется как мусор. Перед enqueue существующий файл удаляется: DownloadManager не перезаписывает, а качает рядом под именем «…-1». Размер берётся `getData().optLong`, а не `getLong`: Capacitor getLong возвращает null для числа, уместившегося в int (проверено по PluginCall.java).

Внутренний `filesDir` DownloadManager не может: он работает в чужом процессе (com.android.providers.downloads) и пишет только во внешнее хранилище; app-specific внешний каталог не требует разрешений (WRITE_EXTERNAL_STORAGE не нужен с API 19), приватен для приложения на Android 11+ и удаляется вместе с приложением. Новых разрешений не добавлено. Перенос в filesDir ради LiteRT-LM не нужен — рантайм принимает путь к файлу.
