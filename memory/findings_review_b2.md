## C. Можно ли было меньшим объёмом
**Правка `accbf18` в списке дня решается локальным обновлением вместо перечитывания.** Сейчас успешная отметка поднимает `dayReloadToken`, эффект перечитывает день из базы, и чтобы список при этом не исчезал, добавлены: второй счётчик, условие `loading && occurrences.length === 0` в `DayTaskList.svelte:44` и комментарий на четыре строки к нему. Альтернатива — в `toggleCompletion` после успешной записи обновить элемент на месте:
`dayOccurrences = dayOccurrences.map((item) => item === occurrence ? { ...item, done } : item);`
Тогда перечитывание дня после отметки не нужно вовсе: `<ul>` не пересоздаётся, фокус с флажка не уходит, «Загрузка задач…» и без условия не мигает, а `monthReloadToken` с `dayReloadToken` снова сводятся к одному счётчику. Экономия — примерно 20 строк из 46, добавленных `accbf18` в `CalendarScreen.svelte` и `DayTaskList.svelte`, плюс два комментария, которые пришлось писать в объяснение обходного пути.
