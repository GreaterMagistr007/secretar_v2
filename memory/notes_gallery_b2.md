## Методика расчёта контраста WCAG

- Каждый канал sRGB нормируется: `c = ch/255`, затем `c <= 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`.
- Относительная яркость `L = 0.2126*R + 0.7152*G + 0.0722*B`.
- Контраст `(Lсветл + 0.05) / (Lтёмн + 0.05)`, округление до 0,01.
- Порог AA для обычного текста — 4.5, для крупного (>=18.66px bold или >=24px) — 3.0. Порог AAA — 7.0.
- Для `rgba`/полупрозрачных слоёв цвет сначала смешивается с фактическим фоном по альфе (`res = fg*a + bg*(1-a)`); такие значения помечены «прибл.».
- Счёт ведётся по значениям из CSS макета, без рендера браузером; наследование цвета проверялось по каскаду вручную.

- Обратная сторона: визуальная плотность держится на точных значениях рамок и отступов — 3px рамка, 2px gap, 3px/4px padding ячейки; при смене кегля или темы эти числа надо пересчитывать вместе.

### Факты, которые стоит знать до выбора

- **Список задач выбранного дня есть только у v11 и v17.** Остальные четыре показывают под сеткой счётчик или фразу: v13 — сводку по месяцу (не по дню), v16 — счётчик дня и качественную оценку, v19 — одну фразу, v20 — счётчик и названия категорий.
- **Выходные не отличаются от рабочих дней у v13, v19, v20; у v17 — только подпись в шапке.** Отличают выходной в самой сетке только v11 (стр. 52) и v16 (стр. 52).
- **Потеря задач в метке:** v11 показывает максимум 3 точки при данных до 3 — совпадает; v16 и v19 показывают 3 при данных до 4 — четвёртая задача не видна и никак не обозначена; v20 показывает 3 при данных до 3 — совпадает; v13 и v17 показывают точное число цифрой, потерь нет.
- **Категорию задачи кодирует только v20** (три цвета + легенда, стр. 132–136, 164). У v11, v16, v17, v19 закодирован один бинарный признак (акцент/важное/горячее/домашнее), причём **без легенды** — значение цвета из интерфейса не восстанавливается (v19 объясняет его текстом в блоке под сеткой, стр. 190).
- **Число ячеек:** только v11 всегда рисует 42 (стр. 194) — высота сетки постоянна. Остальные пять считают `Math.ceil((offset+days)/7)*7`, поэтому высота экрана меняется от месяца к месяцу на 50–110px.
- **Вертикаль:** v19 на шестистрочном месяце не влезает в 844px (−24px), v17 влезает с запасом ≈9px. У v20 и v16 запаса 245–312px, и он ничем не занят.
- **Ни один из шести не имеет тёмной темы как переключаемого режима:** v20 тёмный изначально, `prefers-color-scheme` нет ни в одном файле.
- **Токенизация:** самый чистый по хардкоду — v20 (4 hex), но у него же 21 нетокенизированный `rgba`. Самый бедный набор токенов — v17 (5 переменных, одна из них `--yellow-d` мёртвая). У остальных четырёх одинаковая структура из 9 переменных.
