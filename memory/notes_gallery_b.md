## Метод расчёта контраста
Относительная яркость sRGB по WCAG 2.1: канал c/255 → если ≤0.03928, то c/12.92, иначе ((c+0.055)/1.055)^2.4; L = 0.2126R+0.7152G+0.0722B; контраст = (Lсв+0.05)/(Lтём+0.05), округление до 0,01.
Для цветов, заданных `rgba(...)` поверх фона, выполнено альфа-смешивание с фактическим фоном-родителем — такие оценки помечены «приблизительно».
