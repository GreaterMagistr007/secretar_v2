# Галерея A: 10 вариантов экрана «Календарь»

Агент: gallery-a. Задача: 10 самостоятельных HTML-макетов экрана календаря на месяц
(инлайновый CSS+JS, без внешних зависимостей) в `public/gallery/v01.html` … `v10.html`.
Дата старта: 2026-09-13.

## Общие правила всех вариантов
- doctype html, lang="ru", viewport с viewport-fit=cover.
- Заголовок месяца и года считается в JS от `new Date()`, не хардкодится.
- Клик по блоку месяца открывает рабочую модалку выбора месяца: сетка 12 месяцев,
  переключение года стрелками, активный месяц выделен, закрытие по фону/Esc/«Отмена».
- Сетка дней: неделя с понедельника, дни соседних месяцев приглушены/скрыты,
  сегодня выделено, демо-метки задач генерируются детерминированным хешем (y,m,d).
- Ширина под телефон 360–430 px, горизонтальной прокрутки нет.

## Прогресс по вариантам
- v01 «01. Ясный день / панель сверху» — светло-серый нейтрал, липкая панель сверху:
  стрелки по краям, заголовок-кнопка по центру с подсказкой, кнопка «Сегодня» отдельной
  строкой. Сетка в белой карточке со скруглением, метки задач — точки под числом.
  Модалка — нижний шит (bottom sheet), месяцы сеткой 3x4 сокращениями.
- v02 «02. Тёплый песок / заголовок слева» — бежевая палитра, шрифт с засечками.
  Крупный месяц слева, год под ним разрядкой; справа две круглые стрелки и ссылка
  «Сегодня». Метки задач — короткие горизонтальные штрихи под числом. Модалка —
  центральное окно, месяцы списком в два столбца полными названиями.
- v03 «03. Северный лёд / заголовок-герой» — холодная сине-серая, тёмный герой-блок
  во всю ширину с надписью «Календарь» над месяцем, стрелки и «Сегодня» внутри героя.
  Сетка в белой панели, наезжающей на герой. Метки задач — числовой бейдж в углу
  ячейки. Модалка с цветной шапкой, месяцы 3x4.
- v04 «04. Мятный сад / сегментированный переключатель» — зелёная палитра, компактная
  строка: месяц-кнопка слева, мини-стрелки и «Сегодня» справа; под шапкой декоративный
  сегмент-контрол «Месяц / Неделя / День» (активен «Месяц», клики не навешаны).
  Метки задач — цветные полоски трёх типов (рабочая/личная/важная). Модалка: месяцы 4x3.
- v05 «05. Полночь / нижняя панель навигации» — тёмная палитра, фиксированная нижняя
  таббар-панель с 4 иконками (Календарь активен), заголовок месяца и год сверху слева,
  стрелки и «Сегодня» справа. Ячейки — тёмные плитки, метки задач — светящиеся точки
  двух цветов. Модалка — нижний шит с «грабером».
- v06 «06. Коралловый риф / месяц-таблетка» — коралловый градиент во всю ширину, месяц
  белой «таблеткой» между круглыми стрелками, «Сегодня» наезжает на подложку. Крупные
  ячейки-квадраты 16px радиуса, дни соседних месяцев СКРЫТЫ (пустые ячейки).
  Метки задач — крупные кружки, при >3 задачах вместо них подпись «N задачи».
- v07 «07. Графит / двухстрочная шапка» — почти монохромный графит, месяц капсом крупно,
  год второй строкой с большим трекингом; пара стрелок в рамке и «Сегодня» капсом справа.
  Строка дней недели липкая (position:sticky). Ячейки без карточек, число прижато влево,
  метки задач — вертикальный столбик коротких штрихов (бледный = выполнено).
- v08 «08. Тихий минимализм / тонкие линии» — почти монохром на тёплом белом, только месяц
  и год в две строки, сетка на волосяных линиях, без единой кнопки на экране. Дни соседних
  месяцев скрыты. Сегодня — жирное начертание плюс подчёркивание. Метка задач — один
  штрих переменной длины (1 / 2 / много). Внизу подпись «Сегодня N месяца» и счётчик задач
  месяца. Кнопки «Сегодня» и «Отмена» — только внутри модалки (поэтому addEventListener 8,
  а не 10: нет стрелок «назад/вперёд»).
- v09 «09. Пастельные карточки / шапка с тенью» — пастельная сиренево-розовая палитра,
  шапка отдельной скруглённой карточкой с тенью: месяц в «таблетке», стрелки справа,
  ниже сводка по задачам и кнопка «Сегодня». Ячейки-карточки с тенью, метки задач —
  цветные полоски четырёх категорий с легендой.
- v10 «10. Фиолетовый блок / акцентная шапка» — глубокий фиолетовый блок во всю ширину
  (месяц, стрелки, полоса со счётчиком задач и «Сегодня»), под ним чистая белая сетка.
  День с задачами залит светло-сиреневым, число задач — в круглом счётчике.
