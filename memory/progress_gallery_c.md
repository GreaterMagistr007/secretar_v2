- v23 «23. Material 3 / скруглённые плашки» — готов. Фиолетовый primary #6750a4 + зелёный tertiary, шапка-плашка primary-container со стрелкой, ячейки-квадраты r16, точки задач, чипы статистики, таблетка «Сегодня», центральный диалог.
- v24 «24. Бумага / газетная типографика» — готов. Бежевая бумага, Georgia italic 40px, masthead, двойные линейки, таблица-сетка с линейками, подпись «N дел.» в ячейке, двухколоночная заметка-итог, модалка «Оглавление года» списком в 2 колонки.
- v25 «25. Изумруд / месяц вертикально сбоку» — готов. Вертикальная тёмно-зелёная колонка 74px с writing-mode vertical-rl, сетка справа, задачи как цветная нижняя граница ячейки (3 уровня), блок статистики, модалка 4x3.

- v27 «27. Высокий контраст / крупная доступная сетка» — готов. Ч/б + жёлтый #ffd400, шрифт 18-32px, рамки 4px, инверсные заголовки дней недели, число задач в чёрном бейдже, крупные кнопки, модалка 2 колонки.
- v28 «28. Закат / градиентная шапка и карточка-сетка» — готов. Градиент оранж-розовый-пурпур, скругление шапки 34px снизу, карточка сетки с margin-top -44px поверх шапки, градиентный текст в статистике, bottom sheet.

Команды: ls -l, grep по title / addEventListener / new Date() / Escape / doctype+lang+viewport, grep TODO.

- <title> у всех 10 в формате «NN. Палитра / раскладка», по-русски.
- addEventListener: 8 в каждом (v26 — 9, там ещё лента месяцев). Все обработчики непустые.
- new Date(): 1 вызов в каждом (текущая дата), месяц и год не захардкожены.
- Escape: обработчик закрытия модалки есть во всех 10. Плюс закрытие по фону (e.target===ovl) и по кнопке «Отмена».
- doctype + html lang="ru" + viewport-fit=cover: по 3 совпадения в каждом файле.
