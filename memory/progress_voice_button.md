- Ограниченное декодирование вызова (`ExperimentalFlags.enableConversationConstrainedDecoding`) НЕ включаю: по docs/api/cpp/constrained-decoding.md v0.19.1 оно лишь ограничивает синтаксис вызова («When the model generates function calls ... constrained to follow the function-calling syntax»), вызов не принуждает; для Gemma 4 в gemma4_data_processor.cc:203-212 при сборке с LITERT_LM_TOOL_CALL_CONSTRAINTS_DISABLED даёт FailedPrecondition — лишний риск отказа.
