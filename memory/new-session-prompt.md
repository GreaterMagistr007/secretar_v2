## Как запускать и проверять
- Локально: контейнер `secretar-dev-h33` — `docker start secretar-dev-h33`. Старый `secretar-dev` был смонтирован на прежний путь `/media/user/H_SSD_32/...` и удалён 2026-11-21. Монтирование проверять: `docker inspect -f '{{range .Mounts}}{{.Source}}{{end}}' <имя>`. Создать заново: `docker run -d --name secretar-dev-h33 -p 5173:5173 -v "$PWD":/app -w /app --user "$(id -u):$(id -g)" -e npm_config_cache=/tmp/.npm node:22-alpine npm run dev` → `http://localhost:5173/secretar_v2/`.
- Проверки: `npm run test:coverage`, `npm run check`, `npm run build` в `node:22-alpine`, таймаут от 400000 мс. Зелёный — по коду возврата. Для `grep` по выводу vitest — `-e NO_COLOR=1`, иначе цветовые коды ломают фильтр.

- Браузер без расширения: `playwright-core` из кэша npx и Chromium из `~/.cache/ms-playwright/` — `memory/feedback_tooling.md`.
