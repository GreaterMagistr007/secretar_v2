## Текущий открытый вопрос
**Владелец выбирает вариант дизайна календаря** из галереи. До выбора экран «Календарь» не реализуется.
Следом нужны ответы на вопрос В-6 (маршрут создания задачи из календаря) и вопрос В-7 (устройство экрана календаря: виды, содержимое ячейки, навигация).

## Очередь дальнейших задач
1. Получить выбранный вариант (целиком или частями разных вариантов) → перенести в компонент Svelte, неиспользованные макеты удалить из `public/gallery/`.
2. Закрыть вопросы В-6 и В-7 → реализовать экран «Календарь» (требование Т-11).
3. Хранилище по `docs/architecture_storage.md`: таблицы `tasks` и `completions`, индексы, поиск по описанию. Перед реализацией повторений закрыть вопрос В-8 (перенос повторения при отсутствующей дате).
4. Экран задачи (требование Т-13) и экран настроек с единственной настройкой «тест настройки» (требование Т-12).
5. Позже: Android через Capacitor (решение Р-20), серверная часть и синхронизация (решения Р-22, Р-23).

## Правила, действующие постоянно
- Роль Claude: ведение документации, создание агентов, постановка задач, проверка их результатов (решение Р-6). Реализацию делают агенты.
- Каждое действие сразу фиксируется в документации (решение Р-7).
- По завершении этапа коммит и пуш — обязательны, без запроса (решение Р-8).
- Правка файлов внутри каталога проекта — без запроса (решение Р-9).
- Документация и память — только в каталоге проекта; глобальная память Claude не используется (решение Р-10).
- Вопросы владельцу — только вариантами с плюсами, минусами и рекомендацией; номер всегда с расшифровкой.
- MVP минимальный, берём только то, что можно сделать здесь и сейчас (решение Р-3).
- Сообщение владельцу в Telegram — командой `tlg-send`, по его просьбе.
