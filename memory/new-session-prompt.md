# Промпт новой сессии

## Что прочитать в начале
1. `CLAUDE.md` — правила проекта (читается автоматически).
2. `docs/INDEX.md` — индекс документации.
3. `docs/rules_work.md` — режим работы: роль Claude, агенты, проверка результатов.
4. `docs/product_decisions/00_index.md` — реестр решений Р-1…Р-9.
5. `docs/product_questions.md` — открытые вопросы В-1…В-3.
Целиком документацию не читать, дальше — только файлы под текущую задачу.

## Состояние проекта
Развёрнут каркас правил и документации, реализация не начата, кода нет. `.claude/settings.json` отсутствует — см. вопрос В-4 (создание `.claude/settings.json`). Репозиторий `https://github.com/GreaterMagistr007/secretar_v2`, ветка `master`, каркас запушен.

## Текущий открытый вопрос
**Вопрос В-1 (суть проекта)** — владелец формулирует суть продукта отдельно. До ответа не разворачивать продуктовый контур: `product_goals.md`, `product_scope/`, `req_*.md`. Не выбирать стек и не заводить зависимости — вопрос В-2 (технологический стек) отложен, gate открыт.

## Очередь дальнейших задач
1. Получить от владельца суть проекта (вопрос В-1) → развернуть `docs/product_goals.md` и каталог функционала.
2. Определить минимальный состав PWA-прототипа (решение Р-4 — первый этап PWA-прототип, решение Р-3 — минимальный MVP).
3. Закрыть вопрос В-2 (технологический стек) вариантами с рекомендацией → зафиксировать решением, переписать `docs/tech_stack.md`, дополнить `docs/code_style.md`.
4. Закрыть вопрос В-3 (конфигурация docker-среды) вместе со стеком.
5. Закрыть вопрос В-4 (создание `.claude/settings.json`): файл с разрешениями и хуками проекта не создан — запись в настройки Claude Code заблокирована классификатором auto mode (`[Self-Modification]`). Нужно действие владельца.

## Правила, действующие постоянно
- Роль Claude: ведение документации, создание агентов, постановка задач, проверка их результатов (решение Р-6). Реализацию делают агенты.
- Каждое действие сразу фиксируется в документации (решение Р-7).
- По завершении этапа коммит и пуш — обязательны, без запроса (решение Р-8).
- Правка файлов внутри каталога проекта — без запроса (решение Р-9).
- Вопросы владельцу — только вариантами с плюсами, минусами и рекомендацией; номер всегда с расшифровкой.
- MVP минимальный, берём только то, что можно сделать здесь и сейчас (решение Р-3).
- Документация и память — только в каталоге проекта; глобальная память Claude (`~/.claude/projects/...`) не используется (решение Р-10).
