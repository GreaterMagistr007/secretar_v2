## В-5. Условия публикации на GitHub Pages
**Статус:** решено и выполнено 2026-09-13.
Исходная проблема: репозиторий `GreaterMagistr007/secretar_v2` был приватным (`private: true`), план аккаунта — `free`, `GET /repos/.../pages` → 404. На тарифе `free` GitHub Pages работают только для публичных репозиториев, поэтому выбор стоял между публичным репозиторием, оплатой GitHub Pro и сторонним хостингом. Владелец выбрал публичный репозиторий.
**Выполнено владельцем и проверено через GitHub API 2026-09-13:** `private: false`, `visibility: public`, `has_pages: true`; Pages настроены на `build_type: workflow` (Source — GitHub Actions), адрес сайта `https://greatermagistr007.github.io/secretar_v2/`. Публикаций ещё не было (`status: null`) — первая пойдёт с первым пушем собранного приложения.

## В-4. Создание `.claude/settings.json` с разрешениями и хуками проекта
**Статус:** решено 2026-09-13, файл создан и проверен.
Файл задаёт `defaultMode: acceptEdits`, правила `Edit/Write/NotebookEdit(./**)` и три хука (`PreToolUse` для правок файлов, `PreToolUse` для Bash, `PermissionRequest`) — техническая реализация решения Р-9 (правка файлов проекта без запроса).
**Как решилось:** первые попытки записи — через Bash и через инструмент `Write` — были отклонены классификатором режима auto mode с причиной `[Self-Modification]`; наличие `Bash(*)` в глобальном `permissions.allow` от отказа не спасло. Владелец переключил режим сессии на `accept edits`, после чего файл записался обычным способом. Вывод: запись в настройки Claude Code блокируется именно режимом auto mode, а не permission-правилами.
**Проверено фактическим прогоном хуков** (`jq` 1.7, JSON валиден): правка файла проекта — `allow`; `.env` — исключение, решение остаётся за обычным подтверждением; команда `ls docs` — `allow`; `rm -rf docs` и `cat .env` — исключения; `PermissionRequest` на файл проекта — `allow`.
**Важно:** хуки кэшируются на момент старта сессии — в текущей сессии файл не действует до `/hooks` или перезапуска.

## В-9. Политика контраста тем
**Статус:** в очереди, требуется решение владельца.
Темы перенесены из макетов, которые рисовались как дизайн, а не по стандарту доступности. Измерение по всем 30 темам (см. таблицу в `mechanic_themes.md`): основной текст читается везде, но приглушённые подписи, числа выходных, неактивные вкладки и часть акцентных кнопок ниже порога 4,5:1, худшее значение 1,90.
Варианты: оставить как в макетах · поднять все пары до 4,5:1 · поднять только пары ниже 3,0. Триггер возврата: решение владельца при выборе итоговой темы.
