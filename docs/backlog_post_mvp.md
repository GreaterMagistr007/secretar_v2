# Бэклог за пределами MVP

Сюда попадает всё, что не входит в текущий минимальный объём (решение Р-3 — MVP минимальный, функционал наращивается постепенно). У каждого пункта обязателен **триггер возврата** — событие, по которому пункт снова рассматривается.

Пунктов пока нет: продуктовый контур не развёрнут, вопрос В-1 (суть проекта) открыт.

## Формат пункта
```
### Название
Суть отложенного. Причина отсрочки. **Триггер возврата:** <событие>.
```
