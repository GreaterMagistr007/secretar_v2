# Бэклог за пределами MVP

Сюда попадает всё, что не входит в текущий минимальный объём (решение Р-3 — MVP минимальный, функционал наращивается постепенно). У каждого пункта обязателен **триггер возврата** — событие, по которому пункт снова рассматривается.

### Поиск с середины слова
Позиция каталога 15. Сейчас поиск идёт по префиксу токена с последующей проверкой вхождения — запрос «ажин» в слове «магазин» не находится (см. `architecture_storage.md`, раздел «Поиск по описанию»). Варианты реализации: multiEntry-индекс 3-грамм (быстро, но индекс раздувает базу в десятки раз) либо SQLite WASM + FTS5 (полноценный полнотекстовый поиск ценой 1–2 МБ wasm в бандле). Причина отсрочки: противоречит требованию Т-8 (производительность при росте базы), а спрос на такой поиск не подтверждён.
**Триггер возврата:** владелец сообщает, что поиск не находит нужное из-за начала слова.

### Дата окончания правила повторения
Позиция каталога 16. Регулярная задача сейчас повторяется бесконечно; ограничения «до такого-то числа» или «N раз» нет. Причина отсрочки: в MVP не заявлено (решение Р-3 — минимальный MVP).
**Триггер возврата:** появляется задача, которую нужно прекратить повторять, не удаляя историю.

## Формат пункта
```
### Название
Суть отложенного. Причина отсрочки. **Триггер возврата:** <событие>.
```
