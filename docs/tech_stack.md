# Технологический стек

## Состояние: gate открыт
Стек не выбран. Решение Р-5 (стек определяется по ходу разработки) — причина: указание владельца 2026-09-13 определяться по ходу, а не заранее. Открытый вопрос — В-2 (технологический стек).

**Пока gate открыт, запрещено:** заводить зависимости, конфигурировать сборку, выбирать фреймворк «по умолчанию» и писать код, который этот выбор предрешает.

## Зафиксированные ограничения
- **Первый этап — PWA-прототип** (решение Р-4). Значит: веб-технологии, работа в браузере, манифест и service worker, установка на устройство.
- **Минимальный объём** (решение Р-3): прототип делает то, что можно сделать здесь и сейчас; технологии не выбираются «на вырост».
- **Умолчание по среде:** серверная инфраструктура — в docker-контейнерах (`../CLAUDE.md`, раздел 9). Конкретный состав — вопрос В-3 (конфигурация docker-среды), закрывается вместе со стеком.
- **Платформенно-зависимого кода нет:** различия устройств разработки (Linux, Windows) закрывает контейнер, а не условия в коде.

## Порядок закрытия gate
1. Ответ на вопрос В-1 (суть проекта) и минимальный состав прототипа.
2. Варианты стека владельцу — с плюсами, минусами и рекомендацией.
3. Выбор фиксируется решением в `product_decisions/00_index.md` с причиной.
4. Этот файл переписывается: состав стека, версии, обоснование, ссылки на первоисточники.
5. `code_style.md` дополняется правилами выбранного стека.
