# Стиль кода

Стек не выбран (решение Р-5 — стек определяется по ходу разработки), поэтому здесь только общая часть. Правила конкретного языка и фреймворка добавляются в этот файл при закрытии gate — см. `tech_stack.md`.

## Общие принципы
- SOLID, DRY, KISS. Чистый читаемый код; простое решение предпочитается умному.
- Строгая типизация везде, где язык её позволяет. Отключать проверки типов и глушить ошибки линтера запрещено.
- Комментарии — на русском, только для сложной логики и неочевидных решений; очевидное не комментируется.
- Публичные API документируются в формате, принятом в языке (PHPDoc, JSDoc, docstring, godoc).
- Изучать существующие паттерны проекта перед написанием нового кода и следовать им, а не заводить второй способ делать то же самое.

## Именование
- Идентификаторы, имена файлов кода, ветки, коммиты — английские.
- Тексты документации и комментарии — русские.
- Имена отражают назначение, а не тип: сокращения только общепринятые.

## Ошибки
Ошибка не проглатывается: либо обрабатывается, либо поднимается выше с контекстом. Пустой `catch` без действия запрещён. Сообщение об ошибке содержит то, что нужно для диагностики, и не содержит секретов.

## Тесты
- Юнит-тесты обязательны для каждого модуля с логикой (при ООП — для каждого класса).
- Каждый тест покрывает все пограничные и ключевые значения: границы, пустые и предельные входы, типичные случаи, ошибочные ветки.
- **Тестовые данные хардкодятся прямо в коде теста.** Не из БД, файлов, фикстур или сети.
- **Автотесты не обращаются к базам данных вообще** — ни к dev, ни к prod, ни к выделенной тестовой, ни к sqlite `:memory:`. Зависимости мокаются. Код, который иначе не протестировать, проектируется тестируемым: интерфейсы плюс моки.

## Безопасность
Секреты не попадают в код и репозиторий. Новые переменные окружения — в `.env.example`, `.env` не трогать. Обнаруженный в коде секрет — предупредить владельца немедленно.

## Зависимости
Перед добавлением пакета проверить, нет ли уже аналога в проекте, и обосновать владельцу. Новые каталоги — по согласованию.
