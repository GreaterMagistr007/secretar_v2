## Решения

### Р-1. Название проекта — Secretar
Причина: указание владельца 2026-09-13.

### Р-2. Проект делается с нуля; другие проекты источником не являются
Документация, решения и код других проектов, включая прежнюю версию «secretar», в этот проект не переносятся и при принятии решений не учитываются. Источник истины — только документация этого репозитория и прямые указания владельца.
Причина: указание владельца 2026-09-13.

### Р-3. MVP минимальный, функционал наращивается постепенно
В работу берётся только то, что можно сделать здесь и сейчас. Попытка охватить весь функционал сразу запрещена. Всё, что не входит, — в `backlog_post_mvp.md` с триггером возврата.
Причина: указание владельца 2026-09-13.

### Р-4. Первый этап — PWA-прототип
Начинаем с прототипа в виде PWA.
Причина: указание владельца 2026-09-13.

### Р-5. Стек не выбран, определяется по ходу разработки
Технологический gate открыт, см. `../tech_stack.md`. Единственное зафиксированное ограничение — PWA на первом этапе (решение Р-4).
Причина: указание владельца 2026-09-13 — определяться по ходу разработки, а не заранее.

### Р-6. Роль Claude — документация, агенты, проверка результатов
Зона ответственности Claude: чёткое ведение документации, создание агентов под задачи, постановка задач агентам, проверка результатов их работы на соответствие задаче и исходной просьбе владельца. Реализацию выполняют агенты; Claude правит сам только тривиальное.
Причина: указание владельца 2026-09-13. Детали — `../rules_work.md`.

### Р-7. Каждое действие записывается в документацию
Триггер выполнения = триггер фиксации. Недокументированной работы в проекте не существует.
Причина: указание владельца 2026-09-13.

### Р-8. Коммит и пуш по завершении каждого этапа — обязательны и без запроса
Переопределяет глобальное правило «push только по решению пользователя».
Причина: указание владельца 2026-09-13.

### Р-9. Чтение и правка файлов внутри каталога проекта — без запроса
Подтверждение сохраняется только для секретов, настроек самого Claude Code и разрушительных команд.
Причина: указание владельца 2026-09-13.

## Осознанные решения — не переоткрывать
Решения, принятые с известной ценой и закрытые для обсуждения. Пересмотр возможен единственным путём: владелец сам его поднимает.
- **Р-2 (проект с нуля, другие проекты не источник).** Цена известна: наработки прежней версии не переиспользуются, часть анализа делается заново.
- **Р-3 (минимальный MVP).** Цена известна: заметная часть желаемого функционала уезжает в бэклог и появится позже.
