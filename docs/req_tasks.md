# Требования: задача

Требования Т-1…; номер постоянный, не переиспользуется. Ссылаться только с расшифровкой: «требование Т-4 (регулярность)».

## Т-1. Задача ставится на конкретный день
Задача всегда привязана к календарному дню. Задач без даты не бывает.
Источник: указание владельца 2026-09-13.

## Т-2. Описание
Текстовое поле, формат «Текст», **обязательное**. Пустое описание не сохраняется.
Источник: указание владельца 2026-09-13.

## Т-3. Дата
Формат «Дата», **обязательное**. Значение по умолчанию при создании — **сегодня**. Если создание задачи инициировано из календаря — дата выбранного в календаре дня.
Маршрут создания из календаря владелец объяснит отдельно — вопрос В-6 (маршрут создания задачи из календаря).
Источник: указание владельца 2026-09-13.

## Т-4. Регулярность
Закрытый перечень из пяти значений, пополняется только правкой этого требования:
- «Без повторений»
- «Ежедневно»
- «Еженедельно»
- «Ежемесячно»
- «Ежегодично»
Значение по умолчанию — «Без повторений».
Источник: указание владельца 2026-09-13.

## Т-5. Статус выполнения
Bool: выполнено / не выполнено.
**Для регулярной задачи статус относится только к конкретному повторению**, а не ко всей задаче: если еженедельная задача отмечена выполненной, выполнена она только для этого дня; остальные повторения остаются невыполненными.
Источник: указание владельца 2026-09-13. Техническая реализация — решение Р-15 (модель хранения) и решение Р-16 (отметка выполнения по дате повторения), см. [architecture_storage.md](architecture_storage.md).

## Т-6. Поиск по описанию
Нужна возможность искать задачи **по вхождению в описание**.
Источник: указание владельца 2026-09-13. Реализация — [architecture_storage.md](architecture_storage.md), раздел «Поиск по описанию».

## Т-7. Индексация по дате
Выборка задач по дате идёт по индексу, а не перебором.
Источник: указание владельца 2026-09-13.

## Т-8. Производительность при росте базы
База со временем может стать очень большой. Она не должна тормозить работу и создавать излишнюю нагрузку: рост числа задач и повторений не должен ухудшать отклик экранов.
Источник: указание владельца 2026-09-13. Следствия — повторения не материализуются в хранилище, выборка идёт по видимому диапазону дат (решение Р-15).

## Т-9. Хранение на устройстве
Приложение — PWA, данные хранятся в локальной базе на устройстве. Сервера и синхронизации на этапе MVP нет.
Источник: указание владельца 2026-09-13.
