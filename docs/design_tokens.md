# Дизайн-токены и темы

Тема — это набор именованных значений (токенов), которые задают весь внешний вид приложения: цвета, кнопки, скругления, тени, типографику. Экраны не содержат жёстко прописанных цветов: они обращаются только к токенам, поэтому смена темы перекрашивает всё приложение целиком.

Источник тем — 30 макетов из галереи (`public/gallery/v01…v30.html`, план — [plan_stage_02_calendar_gallery.md](plan_stage_02_calendar_gallery.md)). Из каждого макета вынимаются его стилевые решения и укладываются в общий набор токенов.

## Формат

Тема — объект TypeScript в `src/lib/themes/`:

```ts
export interface Theme {
  id: string;        // 'v01' — совпадает с именем макета
  name: string;      // 'Ясный день' — как в галерее
  layout: string;    // 'панель сверху' — описание раскладки макета
  dark: boolean;     // тёмная ли тема (для meta theme-color и color-scheme)
  tokens: ThemeTokens;
}
```

`ThemeTokens` — строго типизированный набор ключей ниже. Все темы обязаны заполнять **все** ключи: отсутствующий токен ломает экран, который на него рассчитывает. Если в макете значения нет, оно выводится из соседних (например, `colorSurfaceMuted` — из фона со сдвигом светлоты).

## Набор токенов

### Поверхности и текст
| Токен | CSS-переменная | Назначение |
|---|---|---|
| `colorBg` | `--color-bg` | фон экрана |
| `colorSurface` | `--color-surface` | фон карточек, панелей, сетки |
| `colorSurfaceMuted` | `--color-surface-muted` | приглушённая поверхность: чередование, неактивные ячейки |
| `colorText` | `--color-text` | основной текст |
| `colorTextMuted` | `--color-text-muted` | второстепенный текст, дни соседних месяцев |
| `colorBorder` | `--color-border` | границы, разделители, линии сетки |

Имена `colorTaskA/B/C` намеренно нейтральны: прежде они означали категории задач, теперь — приоритеты (требование Т-24). Переименовывать ключи во всех тридцати темах ради смысла не стали, соответствие зафиксировано здесь.
| Токен | CSS-переменная | Назначение |
|---|---|---|
| `colorToday` | `--color-today` | фон или обводка сегодняшнего дня |
| `colorOnToday` | `--color-on-today` | число сегодняшнего дня |
| `colorSelected` | `--color-selected` | выбранный день |
| `colorWeekend` | `--color-weekend` | числа выходных |
| `colorTaskA` | `--color-task-a` | метка задачи, **средний** приоритет |
| `colorTaskB` | `--color-task-b` | метка задачи, **низкий** приоритет |
| `colorTaskC` | `--color-task-c` | метка задачи, **высокий** приоритет |
| `colorDone` | `--color-done` | выполненная задача |

## Применение
Функция `applyTheme(theme)` проставляет все токены как CSS-переменные на `document.documentElement`, выставляет `color-scheme` по признаку `dark` и обновляет `<meta name="theme-color">`. Экраны используют только переменные — ни одного цвета в компонентах.

Выбранная тема хранится в `localStorage` и восстанавливается при запуске; до готовности серверной части (решение Р-22) этого достаточно, позже настройка переедет в профиль пользователя.

## Правила
1. **В компонентах нет литеральных цветов, скруглений и теней** — только `var(--…)`. Исключение: `transparent` и `currentColor`.
2. **Набор токенов закрытый.** Новый токен добавляется правкой этого документа и сразу во все темы — иначе часть тем окажется неполной.
3. **Тема не меняет раскладку**, только оформление: расположение элементов задаётся экраном, а не темой. Поле `layout` хранит описание исходного макета справочно.
4. **Контраст.** Пара «цвет и текст на нём» (`colorPrimary` / `colorOnPrimary` и аналогичные) подбирается читаемой; на тёмных темах светлый текст, на светлых — тёмный.
5. **Значения — самодостаточные**: цвет записывается готовым значением (`#2f4858`, `rgb(...)`, градиент для фона), без ссылок на другие токены, чтобы тему можно было прочитать целиком одним взглядом.
